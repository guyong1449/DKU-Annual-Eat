# DKU Annual Eat

昆山杜克大学校园卡消费报告。采集新数据时本地启动、完成学校 SSO 登录；已保存的报告可随时离线查看。

## 使用

1. 双击根目录的 `启动.cmd`。
2. 工具会打开独立的 Chrome 窗口，并自动恢复已有报告。需要更新流水时，在统计范围中选择 2022 年起的某一年，或「全部年份（2022 年至今）」，点击「采集新数据」。
3. 在自动打开的校园卡标签页完成学校登录及可能的 MFA。程序会自动等待，不需要复制密码、Cookie、授权链接或设置书签。
4. 采集结束后自动在新标签页打开独立报告，默认显示最新年份。用顶部年份和月份选择器切换，所有汇总、图表、窗口标签及明细随之更新，无需再次采集。每次成功采集单独保存快照：JSON 位于 `private/`，新版 HTML 位于 `private/library/`。失败或取消不会清除原报告。
5. 点击「退出工具」退出本工具的专用浏览器和本地服务。常用浏览器不受影响。保存的 HTML 可独立打开，交互图表无需网络。

当前支持 Windows，要求 Node.js 22+ 和 Chrome（找不到时尝试 Edge）。本机已检测到 Node.js 24 和 Chrome，无需额外安装。没有 npm 依赖，无需 `npm install`。这是本地启动版，尚未打包成适用于其他电脑的独立 exe。

**日常查看与书签：** 双击根目录的 `查看报告.html`，打开后按 Ctrl+D 收藏报告库。这个入口是本地文件，退出工具、关闭专用浏览器或重启电脑后仍可查看历史报告。请保留项目目录及 `private/`，移动目录后需更新书签。报告库显示采集范围和保存时间，数据不会自动同步学校流水。

**为什么旧书签会失效：** 旧版采集页使用每次随机变化的本机端口，报告地址也只存在于运行内存；退出服务后这些地址不能工作。直接打开 `dist/index.html` 也缺少本地服务。新版复用本机端口并持久保存报告链接，但 HTTP 地址仍需要工具运行。浏览器书签不能启动本地程序；日常阅读收藏离线报告库，更新流水时双击 `启动.cmd`。

`dist/index.html` 是采集界面的构建文件，单独打开时会提供离线报告库入口和启动说明。普通用户无需启动命令行、安装浏览器插件或编辑配置。

这是个人非官方工具，与学校认证系统无隶属关系。原作者 MIT 许可保留在 `LICENSE`。

## 登录与数据

- 学校负责 SAML SSO 和 MFA。本工具不实现学校认证协议，不接收账号密码。
- 独立浏览器配置位于 `private/browser-session/`，不复制或读取常用 Chrome 配置。专用窗口由 Chrome 正常保存会话，后续能否免登录由学校的会话期限决定。
- 程序启动自己的浏览器调试会话，绑定回环地址，只操作自己创建的校园卡标签页；只有回到 `/dku/index` 后才读取交易表格。学校认证页不注入采集代码。
- 本地服务仅监听 `127.0.0.1`，复用 `private/app-instance.json` 中本项目上次的端口（首次默认 47836）。校验 Host、Origin 和启动时随机生成的请求校验值，不开放 CORS，不提供浏览器配置或项目目录的静态访问。端口被其他程序占用时停止启动，不切换到会破坏书签的新地址。
- 启动时扫描并校验 `private/dku-*.json`，恢复完整快照，损坏或未完成的文件提示后跳过。稳定报告标识保存在 `private/report-library.json`；旧 JSON 和 HTML 不被覆盖。启动时使用现有 JSON 更新 `private/library/` 中的报告样式及 EatTI，无需再次登录。独立导出到其他位置的旧 HTML 不会自动更新。
- 流水不上传第三方；HTML 报告没有外部资源，可以离线打开或通过浏览器打印为 PDF。
- `private/` 包含私人报告、会话配置和诊断日志，已被 Git 忽略。请勿分享或上传该目录。

## 统计口径

- 查询所有账户，可选择 2022 年起的单年或全部年份。全部年份查询 2022-01-01 至中国标准时间当天；往年单年查询完整自然年，当年查询截至今天。报告只提供已查询范围内的年份和月份，零消费期间仍可选择。可查询的历史长度仍取决于学校网站。
- 金额以整数分累加，保留原始正负号。跨年月份分开统计。
- 成功的 `Expense 消费` 扣款计为支出；成功且为正金额的消费冲正、退款和折扣返还作为抵扣。净消费 = 消费扣款 - 实际返还，不再统一乘 0.9。同商户同一天，扣款后 5 分钟内等额返还（含同分钟）按疑似全额退款一对一排除，不计消费笔数；折扣返还不参与配对。原始流水保留，排除明细标明原因。
- 包括餐饮与其他校园消费，但排除 `pharos printing 校园打印` 的扣款及返还；打印记录保留在未计入明细中。不把消费笔数称为用餐次数。
- 按年份从实际交易生成各自的商户标签，展示全部商户；已计入和未计入的明细分开显示。
- 报告包含月度柱状图/折线图、窗口消费占比、全部窗口排行，以及可切换窗口的月度趋势。占比仅计算正净消费，前四个窗口之外合为「其他」，全部金额仍在排行中保留。月均值按查询范围内的月份数计算，包含零消费月份。
- 充值、其他费用及未成功记录保留在明细，但不参与净消费计算。已核实实际 `Expense Canceled 消费冲正` 会抵消原扣款；整笔撤销后重新扣款只留下重新扣款的净额。
- 月度和商户汇总按每条记录的到账时间与商户抵扣；跨年返还计入到账年份，不推断缺失的跨年原订单。选择单月时只统计该月到账记录，扣款笔数与返还笔数分别列示。
- 没有符合统计口径的消费时生成零消费报告。

## 已核实的数据接入

- 登录入口：`https://dkucard.dukekunshan.edu.cn/dku/index`。
- 同源 `POST /dku/searchmydtl`，字段为 `pageNo`、`pager.offset`、`_csrf`、`accid`、`startdate`、`enddate`。
- 日期格式 `YYYY.MM.DD`；每页 6 条，偏移量为 `(pageNo - 1) * 6`。
- 发送 `X-Requested-With: XMLHttpRequest`，解析 HTML 表格与 `Page n/N`。空结果为「暂无交易记录」。
- CSRF 值只在学校页面内随查询发送；浏览器自动携带同源会话。登录重定向、网络错误或超时均停止采集。
- 顺序请求，页间隔 300 ms，单次查询超时 20 秒；最多 3000 页，整体采集最多等待 30 分钟。
- 校验页码、总页数、中间页长度、日期范围与重复交易号，结束后重读第一页。异常和取消不输出假装完整的部分报告。

完整性检查覆盖网站实际返回的分页，不能证明学校后端不存在保留期限、静默截断或延迟入账。第一页复核也不构成数据库快照。中文页面是当前实测目标。

## 开发与验证

### EatTI · 饭格彩蛋

新生成的报告顶部有独立的「EatTI · 饭格彩蛋」入口，与年度消费报告分别筛选年份、月份，不参与主线统计。默认查看全部已采集年份。只读清洗后的扣款，再按商户名称识别餐饮；用途不明的商户（例如便利店）不纳入，排除数量在「这些饭格是怎么来的？」中显示。

候选库共 **25 种角色**，覆盖窗口偏好、路线、时段、花费、消费节奏和周末。先检查匹配门槛，再按规则满足程度排序，每份有效报告最多展示最匹配的 **6 个角色**，不限定类别；不足 6 个按实际匹配数量展示，不补位，没有合适的就不展示。完整候选库放在折叠图鉴中，角色卡可展开实际数据依据。

- 食堂营业范围：**08:00–19:30**；早餐 08:00–09:59、午餐 10:00–13:59、下午加餐 14:00–15:59、晚餐 16:00–19:30（包含 19:30 这一分钟）。营业时间外记录单列，保留在账单和原统计中，不推断夜宵。
- 路线：最高窗口占比 ≥60% 为守护者；至少 4 个窗口且最高占比 <40% 为探险家；其他为漫游者。前两窗口合计 ≥80%、单个均 <60% 时，用双窗口角色替代漫游者。
- 窗口偏好：至少 4 笔、占比 ≥15%。固定小时节奏：营业时段内同一小时至少 6 笔、占比 ≥50%。周末：至少 6 笔、占比 ≥40%。
- 时段及金额档（≤¥15、¥15–30 不含端点、≥¥30）先选笔数最多档。候选以实际占比除以对应门槛排序；时段以 20%、金额以 1/3 为参照，守护者和探险家分别使用最高窗口和其他窗口占比除以 60%，漫游者为 1。总分并列按图鉴顺序，时段/金额档并列按图表顺序并标注。这是可解释的趣味规则，不是心理测评分数或全校人群排名。

至少需要 6 笔餐饮扣款、3 个消费日；不足时提示扩大范围，不捏造结果。三组基础分布仍按实际交易笔数计算，可单独打印饭格或保存 PDF。

实现独立放在 `src/personality.js` 与 `src/personality.css`，随报告内嵌，保持离线可用。配色沿用主报告的深蓝、深绿。`src/assets/eatti-characters-cartoon.png` 是内置 ImageGen 生成的 25 角色卡通图集，以夸张的食物身体、动作和道具突出特征，例如秤形建筑师、计算器精算师和米饭碗干饭家；按图集实际透明间隔，用 SVG 视窗显示各个格子，原图没有后处理。完整提示词保存在同目录的 `eatti-characters-cartoon.prompt.txt`，图集内嵌进 HTML，不依赖外部图片服务。「西式换台手」单独使用 `src/assets/eatti-western-steak.png`，造型为以牛排为身体、戴高厨师帽的卡通牛排角色，配有小表情和短手脚；提示词见同目录 `eatti-western-steak.prompt.txt`。

交互形式参考 [SBTI](https://www.sbmbti.com/) 的角色化趣味结果，命名与匹配规则为本项目设计。报告库中的 HTML 会在启动时根据原 JSON 生成新版；历史原文件和独立导出的 HTML 保持原样。

```powershell
npm test
npm run build
npm start
```

修改 `src/index.html`、`src/app.js` 或 `src/theme.css` 后执行构建，刷新工具页。修改统计、报告或服务端脚本后，通过「退出工具」退出，再重新启动。每次新启动会自动构建采集界面并刷新报告库；重复双击会打开已运行实例，不额外启动一套服务。

- `src/core.js`：交易解析、校验与整数金额统计。
- `src/report.js`、`src/theme.css`：独立交互 HTML 报告与共享界面样式。图表脚本以内联 SHA-256 CSP 授权，数据不加载外部资源。
- `src/collector.js`：校园卡同源查询、分页、取消、超时与完整性检查。
- `src/app.js`、`src/index.html`：本地工具界面。
- `scripts/start.cjs`、`scripts/cdp.cjs`：本地服务与专用浏览器生命周期。
- `scripts/library.cjs`：历史数据校验恢复、稳定链接、原子写入及离线报告库。
- `scripts/launch.ps1`、`启动.cmd`：Windows 双击入口。
- `scripts/build.cjs`：无依赖构建。
- `tests/`：金额、统计口径、异常数据、分页变化与取消测试；`parser.cases.js` 需要浏览器 DOMParser。

2026-09-13 已在真实校园卡会话中验证全年查询与完整分页采集。旧页面曾显示历史内容，但点击下一页进入 SSO：这是会话过期，正常重新登录后恢复。不能把页面可见当作查询仍可用。

遇到问题先查看 `private/app.log`。若提示等待登录，完成专用窗口中的学校登录；若专用窗口已关闭，重新双击启动。不要通过关闭安全设置或复制常用浏览器 Cookie 来恢复。

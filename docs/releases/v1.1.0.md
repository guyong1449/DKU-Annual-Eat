## 简体中文

这是使用 Google Chrome 或 Microsoft Edge 采集校园卡记录的本地应用版。你可以选择统计日期，在学校页面登录后采集消费记录，再查看报告和 Eat TI 饭格。报告支持中英文切换，可以导出卡片、长图或离线网页，也可以通过浏览器打印保存为文件。

如果你需要浏览器插件，或者想使用后来更新的窗口统计和打印布局，请下载 [v1.3.0-beta.1](https://github.com/guyong1449/DKU-Annual-Eat/releases/tag/v1.3.0-beta.1)。本页保留的是 v1.1.0 的本地应用安装包。

### 下载和使用

Windows 电脑下载 [Windows 安装包](https://github.com/guyong1449/DKU-Annual-Eat/releases/download/v1.1.0/DKU-Annual-Eat-1.1.0-win-x64.zip)。苹果电脑根据处理器选择 [Apple 芯片安装包](https://github.com/guyong1449/DKU-Annual-Eat/releases/download/v1.1.0/DKU-Annual-Eat-1.1.0-mac-arm64.zip)或 [Intel 芯片安装包](https://github.com/guyong1449/DKU-Annual-Eat/releases/download/v1.1.0/DKU-Annual-Eat-1.1.0-mac-x64.zip)。完整解压后，Windows 双击 `启动.cmd`，苹果电脑双击 `启动.command`。运行环境已经放在包里，无需另外安装 Node.js。苹果电脑需要 macOS 13.5 或更新版本。

在工具页面选择日期范围，点击“采集新数据”，再到工具打开的学校页面完成统一身份认证和多因素身份验证。登录完成后会继续采集。报告保存后，可以通过 `查看报告.html` 再次打开，离线时也能阅读；需要新记录时再运行启动文件。

这一版的采集需要 Google Chrome 或 Microsoft Edge。只有 Safari 的苹果电脑需要安装其中一个浏览器，或改用后续的 Safari 测试版。苹果电脑安装包的启动和学校登录尚未完成真机验收。

如果 macOS 首次启动时拦截了文件，请按安装包内的 `使用说明.txt` 和 `安全性设置方法.png` 操作，在“系统设置 → 隐私与安全性”中允许打开对应文件。

### 保留旧数据

更新前先退出旧工具并备份 `private/` 文件夹。将新版完整解压到新的文件夹，把旧版的 `private/` 复制进去，再启动新版。独立导出的旧网页不会自动更新，需要重新打开报告并再次导出。

## English

This local application collects campus card transactions through Google Chrome or Microsoft Edge. Choose a date range, sign in on the school page, and collect your records to view the spending report and Eat TI dining characters. Reports work in Chinese and English and can be exported as cards, long images or standalone web pages. You can also save a document from the browser print dialog.

For the browser extension or the later counter-statistics and print-layout changes, use [v1.3.0-beta.1](https://github.com/guyong1449/DKU-Annual-Eat/releases/tag/v1.3.0-beta.1). The downloads on this page remain the v1.1.0 local application packages.

### Download and use

For Windows, download the [Windows package](https://github.com/guyong1449/DKU-Annual-Eat/releases/download/v1.1.0/DKU-Annual-Eat-1.1.0-win-x64.zip). For an Apple computer, choose the [Apple silicon package](https://github.com/guyong1449/DKU-Annual-Eat/releases/download/v1.1.0/DKU-Annual-Eat-1.1.0-mac-arm64.zip) or the [Intel package](https://github.com/guyong1449/DKU-Annual-Eat/releases/download/v1.1.0/DKU-Annual-Eat-1.1.0-mac-x64.zip). Extract the entire archive and double-click `启动.cmd` on Windows or `启动.command` on an Apple computer. The runtime is included, so you do not need to install Node.js separately. Apple computers require macOS 13.5 or later.

Choose a date range and select Collect new data. Complete the school single sign-on and multi-factor authentication in the page opened by the tool, and collection will continue. Once a report has been saved, open `查看报告.html` to read it again, even offline. Run the launcher when you want new records.

Collection in this version requires Google Chrome or Microsoft Edge. If an Apple computer only has Safari, install one of these browsers or use a later Safari preview. Launch and school sign-in for these Apple application packages have not yet been verified on a physical Apple computer.

If macOS blocks a file on first launch, follow the included `使用说明.txt` instructions and `安全性设置方法.png` image to allow the file in System Settings → Privacy & Security.

### Keep your existing data

Exit the old tool and back up its `private/` folder before updating. Extract the new version into a separate folder, copy `private/` into it, and launch the new version. Independently exported web pages do not update automatically; reopen the report and export it again.

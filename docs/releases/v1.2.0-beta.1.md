# v1.2.0-beta.1

这一版为 Mac 增加 Safari 采集后端。只有 Safari 的电脑可以使用系统自带的 AppleScript/JXA 接口采集校园卡流水，首次使用需要配置 Safari 和 macOS 的自动化权限。

This beta adds a Safari collection backend for Mac. Computers with Safari can use the built-in macOS AppleScript/JXA interface to collect campus card records. First-time use requires Safari and macOS automation permissions.

## Safari 采集 · Safari collection

- Mac 工具页新增采集浏览器选择。工具优先选择已安装的 Chrome 或 Edge，只有 Safari 时自动选择 Safari。

  The Mac tool page now has a collection browser selector. It selects an installed Chrome or Edge first and falls back to Safari.

- 工具创建独立 Safari 窗口，等待用户完成学校 SSO 和 MFA，再复用现有分页校验、统计与报告逻辑。执行采集脚本前会核对窗口和校园卡域名。

  The tool creates a dedicated Safari window, waits for school SSO and MFA, then uses the shared pagination checks, calculations, and reports. It checks the window and campus domain before executing collection scripts.

- 缺少权限、窗口关闭或标签页变化时，界面提供对应的中英文提示。取消采集会终止查询，退出时清理工具登记的 Safari 窗口。

  The interface provides Chinese and English guidance for missing permissions, closed windows, and changed tabs. Cancellation aborts collection, and quitting closes the Safari windows registered by the tool.

## 首次使用 · First-time setup

1. 在 Safari 设置 → 高级中显示开发者功能，再到开发者设置开启“允许来自 Apple Events 的 JavaScript”。

   In Safari Settings → Advanced, show features for web developers. Then enable Allow JavaScript from Apple Events in Developer settings.

2. 开始采集时，允许 macOS 弹窗中的启动程序控制 Safari，通常显示为“终端”。这项授权可在系统设置 → 隐私与安全性 → 自动化中管理。

   When collection starts, allow the launching app shown in the macOS prompt to control Safari, usually Terminal. Manage this consent in System Settings → Privacy & Security → Automation.

3. 在新开的 Safari 窗口完成学校登录和 MFA，采集期间保留原来的单个标签页。

   Complete school sign-in and MFA in the new Safari window and keep its original single tab open during collection.

Mac 包内附有中英 `使用说明.txt` 和 `安全性设置方法.png`。Safari 的登录状态由 Safari 自身管理，流水与报告保存在本机 `private/` 中。

Each Mac package includes bilingual `使用说明.txt` instructions and the `安全性设置方法.png` illustrated guide. Safari manages its own sign-in state. Records and reports are stored locally in `private/`.

## 下载与更新 · Download and update

完整解压对应的 ZIP，再运行 Windows 的 `启动.cmd` 或 Mac 的 `启动.command`。包内自带 Node.js。Mac 需要 macOS 13.5+，Windows 使用 Chrome 或 Edge。

Extract the entire ZIP, then open `启动.cmd` on Windows or `启动.command` on Mac. Node.js is included. Mac requires macOS 13.5+. Windows uses Chrome or Edge.

| 系统 / Platform | 压缩包 / Archive |
| --- | --- |
| Windows x64 | `DKU-Annual-Eat-1.2.0-beta.1-win-x64.zip` |
| macOS Apple 芯片 / Apple silicon | `DKU-Annual-Eat-1.2.0-beta.1-mac-arm64.zip` |
| macOS Intel | `DKU-Annual-Eat-1.2.0-beta.1-mac-x64.zip` |

每个 ZIP 都附有 `.sha256` 校验文件。更新时先退出旧工具并备份 `private/`，将新版解压到新文件夹，把旧版 `private/` 复制到新版目录后启动。

Each ZIP has a matching `.sha256` checksum file. To update, exit the old tool and back up `private/`, extract the new ZIP into a separate folder, copy the old `private/` into it, then launch the new version.

## 验证范围 · Verification

97 项自动检查全部通过，涵盖共享采集流程、Safari 传输层模拟、权限错误提示、域名与窗口限制、取消和退出清理、本地 API，以及三个平台包的内容和校验值。Windows 已验证正常启动及包内运行时加载。

All 97 automated checks pass, covering the shared collection flow, simulated Safari transport, permission errors, domain and window restrictions, cancellation and shutdown cleanup, the local API, and all three packages’ contents and checksums. Windows startup and bundled runtime loading have also been verified.

Safari 真机上的首次权限弹窗、学校 SSO/MFA 和图片导出尚待验收，因此作为预发布测试版提供。Mac 包经过跨平台构建和归档检查，尚未完成 Apple 签名或公证。

First-run permission prompts, school SSO/MFA, and image exports still need verification in Safari on a physical Mac, so this is a prerelease beta. Mac packages are cross-built and checked for archive integrity. They are unsigned and unnotarized.
